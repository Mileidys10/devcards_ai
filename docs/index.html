Núcleo de Dominio (Domain Core)

El corazón del negocio

El Dominio contiene exclusivamente Entidades de Negocio, Objetos de Valor (Value Objects) y Reglas de Negocio Puras. Es completamente agnóstico a la tecnología: NO importa Spring, ni Angular, ni Hibernate, ni SQL.

🔑 Ejemplos Concretos de esta Capa:

  • Entidad CuentaBancaria con método debitar()
  • Objeto de Valor Dinero(monto, moneda)
  • Regla: "No se puede transferir un monto negativo"
💡 Regla Sagrada: Las capas externas conocen a las internas. El Dominio NUNCA conoce a la base de datos ni a la interfaz web.
